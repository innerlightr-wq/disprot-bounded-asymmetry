# Revision Addendum

This directory contains supplementary materials prepared following an independent external methodological review of the repository and accompanying manuscript. The purpose of these materials is to strengthen the statistical interpretation of the bounded asymmetry profile analysis while preserving the complete reproducibility of the original study.

## Contents

### `ADDENDUM_permutation_calibration.pdf`

A technical addendum describing the rationale, implementation, and interpretation of the permutation calibration performed following methodological review. The document explains why the additional analysis was performed and how it should be interpreted alongside the primary results.

### `permutation_results.csv`

Machine-readable output from the permutation calibration analysis used in the addendum. These data allow independent verification of the reported statistical summaries.

### `bounded-asymmetry-profiles-cross-taxon-protein-disorder-2026.pdf`

The deposited manuscript version that accompanied this addendum. **It is not a corrected manuscript.** Its text is substantively identical to `paper/manuscript.pdf` — a normalised text comparison differs only in reference line-wrapping and one Zenodo DOI — the word "permutation" does not appear in it, and its abstract still asserts the localisation claim that Section 5 of the addendum withdraws. Read `ADDENDUM_permutation_calibration.pdf` for the current conclusions. (Corrected 2026-09-18; this file previously described the PDF as "the revised manuscript incorporating the additional statistical calibration".)

## Purpose

The original repository already contained a fully reproducible computational workflow. This addendum extends the statistical evaluation by providing an additional permutation-based calibration of the asymmetry profile analysis. The original analyses, code, data, and conclusions remain fully available and reproducible.

The addendum is intended to increase methodological transparency and to provide readers with an additional validation layer for interpreting localized profile structure.

## Reproducibility

All original data, analysis scripts, and computational environment remain unchanged except for the additional materials contained in this directory. The repository continues to provide a deterministic and reproducible research workflow.
